## アカウントと登録

方針：**登録の手間をなくし、最初の画面からすぐ始められるようにする。**
アカウントは裏で自動的に作り、データを守る必要が出た時点で Apple のアカウントにつなぐ。

| 番号 | 要件 |
|---|---|
| R-08-01 | 初回起動時、利用者に何も入力させずにアカウントを自動で作る（Firebase の匿名認証） |
| R-08-02 | 「Appleでサインイン」でアカウントを守れるようにする。ボタン1つで、メールアドレスやパスワードの入力はない |
| R-08-03 | 次の場面で、Appleでサインインを勧める：家族グループを作るとき・参加するとき、記録が7日分（仮）たまったとき。断っても使い続けられる |
| R-08-04 | 機種変更のとき、Appleでサインインしていればデータを引き継げる。していない場合は引き継げないことを、勧める画面で伝える |
| R-08-05 | 家族の招待は、リンクと6桁の招待コードの両方で受けられる。アプリを入れた後に招待コードを貼り付けるボタンを用意する |
| R-08-06 | 名前は「呼び名」だけを入力する（家族の中での呼び方。本名でなくてよい） |
| R-08-07 | 年齢・性別・住所・電話番号は聞かない |

### 招待リンクの扱い

アプリを入れていない人がリンクを開いた場合、アプリを入れた後に自動で招待を受ける仕組み（遅延ディープリンク）が必要になる。
以前よく使われた Firebase Dynamic Links は提供が終了しているため、次のどちらかで行う。

- リンクを開くと Web ページが開き、招待コードと App Store のボタンを表示する。アプリを入れたら招待コードを貼り付ける（自前で作れる。MVPはこちら）
- 外部サービス（Branch など）で、自動で招待を受けられるようにする（後で検討）

## アカウント削除

App Store の審査ガイドライン（5.1.1）で、アカウントを作れるアプリには、アプリ内からアカウントを削除できることが求められる。
利用を止めるだけ（無効化）では足りず、アカウントと関連するデータを削除する必要がある。

| 番号 | 要件 |
|---|---|
| R-08-20 | 設定画面から、アプリ内だけでアカウントを削除できる。Webサイトや問い合わせに案内するだけにしない |
| R-08-21 | 削除の前に、消えるものを一覧で見せ、2段階で確認する（高齢の方の誤操作を防ぐため） |
| R-08-22 | 削除するもの：プロフィール、薬と服薬スケジュール、服薬記録、歩数、ゲームの進み具合、スタンプ、本人が受け取った応援 |
| R-08-23 | 家族の画面に残るもの：本人が送った応援スタンプは「退会したメンバー」と表示し、名前を消す |
| R-08-24 | 家族グループの作成者が削除する場合、残るメンバーに作成者を引き継ぐ。最後の1人なら家族グループも削除する |
| R-08-25 | 見守っていた家族には「見守りが終了した」ことを知らせる |
| R-08-26 | 端末内のデータと、予約済みの服薬通知も削除する |
| R-08-27 | Appleでサインインを使っていた場合は、Apple 側の連携も解除する（Apple の要件） |
| R-08-28 | 削除の処理はサーバー（Cloud Functions）で行い、関連するデータをまとめて消す |
| R-08-29 | 匿名のまま使っている人も、同じ画面からデータを削除できる |
| R-08-30 | バックアップに残るデータの保存期間を、プライバシーポリシーに書く |
