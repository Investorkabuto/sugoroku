# 11 収益化

状態：下書き

## 方針

健康管理の機能（服薬、通知、記録、見守りの基本）は無料のままにする。
収益は、旅の楽しみと家族の安心に結びつく形で得る。

## 収益の候補

| 候補 | 内容 | 時期 | 注意点 |
|---|---|---|---|
| ご当地おみやげのアフィリエイト | スタンプを取った名物を、通販サイトで買えるリンクを出す（Amazon、楽天など） | 第2段階 | 広告であることを表示する。料率は数%のため、利用者が多くないと収益は小さい |
| ふるさと納税のアフィリエイト | 旅した土地の返礼品を紹介する | 第2段階 | ご当地の旅と相性がよい。紹介する返礼品の選び方を決める |
| 家族への贈り物 | 家族がアプリから、旅先の名物を本人に贈る | 第3段階 | 交流の層とつながる。送り先の住所を扱うため、個人情報の扱いが増える |
| デジタルアイテム | 駒の着せ替えやスタンプ帳の飾り | 第2段階 | 買い切りのみ。App Store のアプリ内課金を使う。ガチャは入れない |
| 家族向け見守りプラン | 見守りの詳細な機能を、見守る家族側が月額で使う | 第2段階 | 本人の基本機能は無料のまま |
| 自治体・観光協会との提携 | ご当地のマスやクイズの協賛 | 将来 | 運営の実績ができてから |

## 要件

| 番号 | 要件 |
|---|---|
| R-11-01 | MVPには収益化の機能を入れない。ただし、名物のデータに通販リンクを持たせられる形にしておく |
| R-11-02 | 広告やアフィリエイトのリンクには「PR」と表示する（ステルスマーケティング規制への対応） |
| R-11-03 | 健康データ（服薬、歩数、病歴）は、広告の出し分けにも外部の事業者にも使わない |
| R-11-04 | 名物を勧める文章に、健康への効果をうたう表現を使わない |
| R-11-05 | 高齢の方が誤って購入しないよう、外部サイトに移る前に確認を表示する |
| R-11-06 | 実物の商品は外部サイトで購入する。アプリ内で使うデジタルの品は App Store のアプリ内課金で販売する |
