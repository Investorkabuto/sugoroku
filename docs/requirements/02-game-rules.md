# 02 ゲームルール

状態：下書き

## 設計の原則

ゲームは健康管理を続けるための楽しみであり、健康管理の条件にはしない。

| 番号 | 原則 |
|---|---|
| P-02-01 | **健康の流れとゲームの流れを切り離す。** 服薬の記録は通知のボタンだけで完結し、アプリを開かなくても残る。見守りの判定には「記録があるか」を使い、「アプリを開いたか」は使わない |
| P-02-02 | **やらないと損をする仕組みを作らない。** 期限で消えるごほうび、毎日のログインボーナス、連続記録の表示は入れない |
| P-02-03 | **マイナスの出来事を作らない。** マスが戻る、何かを失うといった要素は入れない |
| P-02-04 | **正直な記録にごほうびを出す。** 「飲み忘れた」「スキップ」と記録しても、記録として数える |
| P-02-05 | **ゲームと交流の通知は、初期状態でオフにする。** 服薬の通知の重みを保つ |
| P-02-06 | **有料ガチャを入れない。** 収益化の方針は 11 で扱う |
| P-02-07 | **文字の大きさや操作の簡単さを変えても、すべての遊びができる。** 速い反応を求める遊びは作らない |

## 層の構成

| 層 | 中身 | 何で動くか | MVP |
|---|---|---|---|
| 旅の層 | サイコロ、すごろくの移動、ご当地スタンプ | 健康の記録 | ○ |
| 遊びの層 | ご当地クイズ（将来：ミニゲーム、飾り付け、旅のアルバム） | いつでも自由 | クイズのみ |
| 交流の層 | 家族と同じ地図を旅する、応援スタンプ、一緒に挑むイベント | 自由 | ○（家族のみ。10 で扱う） |

| 番号 | 要件 |
|---|---|
| R-02-01 | 遊びの層と交流の層の結果は、すごろくの進む速さに影響しない（見た目やコレクションに反映する） |

## サイコロと旅ポイント

サイコロはいつでも何度でも振れる（旧C案、2026-10-16）。
健康の記録のごほうびは「旅ポイント」（名前は仮）とし、引き換え所でいろいろなものと交換する。

| 番号 | 要件 |
|---|---|
| R-02-05 | サイコロは回数の制限なく、いつでも振れる |
| R-02-06 | 旅ポイントは健康の記録と歩数でだけ貯まる。お金では買えない（P-02-06） |
| R-02-07 | 旅ポイントに期限を付けない（P-02-02） |
| R-02-08 | 引き換え先は「旅を楽しくするチケット（例：観光券。名所で使うと名物スタンプ）」と「見た目（アバター、飾り）」の2種類。MVPは観光券と数種類のアバターだけにする |
| R-02-09 | 旅ポイントや引き換えたものは、次の地域へ進む条件にしない。どれと引き換えても損をしないようにする |

ごほうびについて守ること：

| 番号 | 要件 |
|---|---|
| R-02-10 | 健康の記録のごほうびは、振る回数を増やしても価値が下がらない形にする |
| R-02-11 | ごほうびの量は達成率で決め、薬の数が多い人と少ない人で不公平にならないようにする |
| R-02-12 | 歩数は歩いた分だけ旅ポイントになる（従量制、1日の上限あり）。本人が自分で決めた目標歩数に届いた日は上乗せする（詳細は 04） |
| R-02-13 | アプリを開いただけでは、ごほうびは届かない |
| R-02-14 | 取り逃しを作らない。観光券を持たずに名所を通っても、後から取り戻せるか、アプリ内の表示だけで済ませ、通知はしない |
| R-02-15 | 1日の区切りは午前3時（仮）。午前0時〜3時の記録は前の日の分として数える |
| R-02-16 | まとめて振る操作を用意する |
| R-02-17 | 旅ポイントの付与は、サーバーの時刻と記録で判定する（端末の時刻を変えても増えない） |
| R-02-18 | 家族のおすそわけ（R-10-23）は、1日1回、少しの旅ポイントを贈る形にする |

## すごろくの盤面

| 番号 | 要件 |
|---|---|
| R-02-20 | 盤面は1本道のマスの列。MVPは1地域分 |
| R-02-21 | マスの種類：ふつうのマス、ご当地スタンプのマス、クイズのマス、健康ミニ知識のマス |
| R-02-22 | ゴールに着いたら、乗り物で次の地域へ進める。地域は章として扱い、次の行き先は本人が選ぶ（MVPでは同じ地域の2周目。詳細は 12） |
| R-02-23 | マスと名物のデータはサーバーから配信し、アプリにも初期データを同梱する（通信できないときに使う） |
| R-02-24 | 盤面は家族で共有し、一人ひとりが自分の駒（アバター、R-12-10）を持つ。家族の進み方は連動させない（R-12-06）。順位は表示しない |

## ご当地クイズ（遊びの層）

| 番号 | 要件 |
|---|---|
| R-02-30 | クイズのマスに止まると、その土地のクイズが出る。3択、時間制限なし |
| R-02-31 | 通った地域のクイズは、クイズの画面からいつでも何度でも遊べる |
| R-02-32 | 正解すると「知識バッジ」がスタンプ帳に付く。進む速さには影響しない |
| R-02-33 | 間違えても何も失わない。解説を表示する |
