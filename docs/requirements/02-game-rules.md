# 02 ゲームルール

状態：下書き

## 設計の原則

ゲームは健康管理を続けるための楽しみであり、健康管理の条件にはしない。

| 番号 | 原則 |
|---|---|
| P-02-01 | **健康の流れとゲームの流れを切り離す。** 服薬の記録は通知のボタンだけで完結し、アプリを開かなくても残る。見守りの判定には「記録があるか」を使い、「アプリを開いたか」は使わない |
| P-02-02 | **やらないと損をする仕組みを作らない。** 期限で消えるごほうび、毎日のログインボーナス、連続記録の表示は入れない |
| P-02-03 | **マイナスの出来事を作らない。** マスが戻る、何かを失うといった要素は入れない |
| P-02-04 | **正直な記録にごほうびを出す。** 「飲み忘れた」「スキップ」と記録しても、記録として数える |
| P-02-05 | **ゲームと交流の通知は、初期状態でオフにする。** 服薬の通知の重みを保つ |
| P-02-06 | **有料ガチャを入れない。** 収益化の方針は 11 で扱う |
| P-02-07 | **文字の大きさや操作の簡単さを変えても、すべての遊びができる。** 速い反応を求める遊びは作らない |

## 層の構成

| 層 | 中身 | 何で動くか | MVP |
|---|---|---|---|
| 旅の層 | サイコロ、すごろくの移動、ご当地スタンプ | 健康の記録 | ○ |
| 遊びの層 | ご当地クイズ（将来：ミニゲーム、飾り付け、旅のアルバム） | いつでも自由 | クイズのみ |
| 交流の層 | 家族やなかまとのスタンプ、メッセージ、一緒に挑むイベント | 自由 | ×（10 で扱う） |

| 番号 | 要件 |
|---|---|
| R-02-01 | 遊びの層と交流の層の結果は、すごろくの進む速さに影響しない（見た目やコレクションに反映する） |

## サイコロ

サイコロは「記録で届く分」と「時間で届く分」の2つの入り口から届き、同じ箱に貯まる。
健康の記録が旅の主な原動力になるよう、記録で届く分を多くする。

| 番号 | 要件 |
|---|---|
| R-02-10 | **記録のサイコロ**：健康の記録をするたびに、その場で届く |
| R-02-11 | 記録のサイコロは1日に最大3個。その日の予定の達成率に応じて、最初の記録で1個目、50%（仮）で2個目、100%で3個目が届く。薬の数が多い人と少ない人で不公平にならないようにするため |
| R-02-12 | 歩数が本人の普段の歩数を上回った日は、記録のサイコロが1個増える（詳細は 04） |
| R-02-13 | **時間のサイコロ**：記録とは関係なく、12時間（仮）ごとに1個届く（1日2個）。記録できない日があっても旅が止まらず、ゲームだけを楽しみたい日にも振れるようにするため |
| R-02-14 | 1日に届くサイコロは最大6個（記録3＋歩数1＋時間2）。記録で届く分が全体の3分の2になるようにする |
| R-02-15 | 届いたサイコロは同じ箱に貯まり、好きなときに振れる。箱の上限は30個（約5日分、仮）。上限を超えた分は届かないが、アプリ内で「いっぱい」と表示するだけで通知はしない |
| R-02-16 | アプリを開いただけでは、サイコロは届かない |
| R-02-17 | 1日の区切りは午前3時（仮）。午前0時〜3時の記録は前の日の分として数える |
| R-02-18 | サイコロは1個ずつ振る。まとめて振る操作も用意する |
| R-02-19 | 時間のサイコロは最後に届けた時刻を記録し、端末の時刻が戻されたときは届けない。時刻を先に進められた場合はMVPでは防げないが、箱の上限（R-02-15）で影響を抑える。サーバーの時刻を使う対策は第2段階で行う |

## すごろくの盤面

| 番号 | 要件 |
|---|---|
| R-02-20 | 盤面は1本道のマスの列。MVPは1地域分 |
| R-02-21 | マスの種類：ふつうのマス、ご当地スタンプのマス、クイズのマス、健康ミニ知識のマス |
| R-02-22 | ゴールに着いたら、次の地域へ進める（MVPでは同じ地域の2周目） |
| R-02-23 | マスと名物のデータはアプリに同梱し、後からサーバー配信に切り替えられる形式にする |

## ご当地クイズ（遊びの層）

| 番号 | 要件 |
|---|---|
| R-02-30 | クイズのマスに止まると、その土地のクイズが出る。3択、時間制限なし |
| R-02-31 | 通った地域のクイズは、クイズの画面からいつでも何度でも遊べる |
| R-02-32 | 正解すると「知識バッジ」がスタンプ帳に付く。進む速さには影響しない |
| R-02-33 | 間違えても何も失わない。解説を表示する |
