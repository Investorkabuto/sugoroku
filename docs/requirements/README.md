# 設計要件

健康すごろくアプリの設計要件を、要素ごとに1ファイルずつまとめる。
元になる構想は Claude Docs の「健康すごろくアプリ 基本構想」。

## 書き方

- 決まったことは「要件」、まだ決めていないことは「未決事項」に分ける
- 仮の値には（仮）と付け、試作で決める
- 要件には `R-01-03` のような番号を付け、他の要素から参照できるようにする
