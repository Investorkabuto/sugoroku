# 12 キャラクターとテーマ

状態：下書き（2026-10-16）

## 方針

**自分のアバターが、相棒の動物と一緒に日本を歩いて旅する。地域から地域へは乗り物でひとっ飛びする。**
絵柄は和風（日本らしい、やわらかい絵）にし、高齢の方にも子どもにもなじみやすくする。

## 旅の形

| 番号 | 要件 |
|---|---|
| R-12-01 | 地域の中は、アバターが歩いて名所や宿場を巡る（歩数で進む仕組みと合わせる、04） |
| R-12-02 | 地域のゴールに着いたら、乗り物（列車、船、飛行機など）で次の地域へ移る。移る場面は、地域をクリアしたお祝いの演出にする |
| R-12-03 | 地域は「止まる壁」ではなく「章」として扱う。道は1本につながったまま、地域の終わりで乗り物の演出とお祝いが入る |
| R-12-04 | 地域をクリアするたびに、次に行く地域を本人が選べる（MVPは1地域のため、同じ地域の2周目、R-02-22） |
| R-12-05 | 地域ごとにスタンプ帳のページを「完成」させられる |
| R-12-06 | 家族の進み方は連動させない。家族はそれぞれのペースで旅をし、別の地域にいてもよい（R-10-20） |
| R-12-07 | 家族の居場所は日本地図の上で見られる。同じ地域にいる家族は、盤面の上にも駒が出る |

地域で区切る理由：

- 2〜4週間ごとに「○○を制覇」という節目ができ、続ける理由になる
- 次の行き先（出身地、思い出の土地など）を選ぶことが、家族の会話のきっかけになる
- MVPは1地域だけ作り、あとから地域を足していける。季節のイベントも地域単位で組みやすい

## キャラクター

| キャラクター | 役割 |
|---|---|
| アバター（本人・家族一人ひとり） | 盤面の駒。人の姿で、旅装束などに着せ替えられる |
| 相棒 | 一人ひとりが選ぶ旅の連れの動物。アバターの横を一緒に歩き、案内や声かけをする |

| 番号 | 要件 |
|---|---|
| R-12-10 | 駒は一人ひとりのアバターにする。最初に数種類から選べ、選ばなくても初期のアバターで旅を始められる（R-10-06） |
| R-12-11 | 相棒は一人ずつ、数種類の動物から選ぶ。候補は日本らしい動物にする（例：柴犬、三毛猫、たぬき、うさぎ、きつね。仮） |
| R-12-12 | 家族の駒は、アバターと相棒の組み合わせで見分けられるようにする（R-05-40）。色だけに頼らない（R-05-84） |
| R-12-13 | 相棒は、マスの案内、名物やクイズの紹介、地域クリアのお祝いを話す。アプリ内の言葉づかいはやさしく、責めたり急かしたりしない（P-02-02、P-02-03） |
| R-12-14 | 相棒は服薬を指示しない。服薬の通知の文面には相棒を出さず、通知の重みを保つ（P-02-05、08） |
| R-12-15 | 相棒は、あとから選び直せる。選び直しても集めたものは失わない（P-02-03） |
| R-12-16 | アバターの着せ替え（旅装束、帽子、小物など）は、旅ポイントの引き換え先にする（R-02-08）。将来の買い切りのアイテム（11）も同じ枠に入れる |
| R-12-17 | 乗り物の見た目（例：ご当地の列車）は、将来の引き換え先の候補にする。MVPには入れない |

## 絵柄とテーマ

| 番号 | 要件 |
|---|---|
| R-12-20 | 絵柄は和風にする。和紙の質感、日本の伝統色、千代紙のような柄を使い、やわらかく温かい印象にする |
| R-12-21 | 和風の飾りより読みやすさを優先する。文字は飾り文字にせず、背景の柄は文字の後ろに重ねない（R-05-80〜R-05-87） |
| R-12-23 | 和風の色合いは、ダークモードでも同じ印象になるよう、明るい場合と暗い場合の2通りを用意する（R-05-86） |
| R-12-22 | 画面の名前や言葉にも旅の言葉を使う（例：スタンプ帳、観光券、引き換え所）。健康の画面（今日のやること）は落ち着いた見た目にし、ゲームの飾りを入れすぎない（P-02-01） |
