# 05 画面構成と操作の流れ

状態：下書き（2026-10-16 更新：ホームを「今日のやること」と「ゲームをはじめる」の2つの入り口に分ける）

## 方針

**ホームには「今日のやること」と「ゲームをはじめる」の2つの大きな入り口を置き、健康の管理とゲームをはっきり分ける。**
「今日のやること」からは、服薬のスケジュールや歩数などの管理に進む。「ゲームをはじめる」からは、すごろくのゲームモードに入る。
服薬の記録は通知のボタンで完結するため（P-02-01）、アプリを開くのは「確かめたいとき」と「遊びたいとき」と考え、その2つをそのまま入り口にする。
高齢の方が迷わないよう、画面の下に並ぶタブは使わず、どの画面からも1回でホームへ戻れるようにする。
文字の大きさや操作の簡単さを変えても、すべての機能が使える（P-02-07）。

## 言葉の決まり

| 言葉 | 意味 |
|---|---|
| 入り口 | ホームに置く大きなボタン。「今日のやること」と「ゲームをはじめる」の2つ |
| 今日のやること | 服薬、歩数、記録、薬の登録など、健康の管理をする画面のまとまり |
| ゲームモード | すごろく、クイズ、スタンプ帳、引き換え所など、遊ぶ画面のまとまり |
| 画面番号 | `S-01` のような画面の番号。06・07・09 から参照する |
| 案内 | 初回起動のときに一度だけ通る画面の流れ |

## 画面の全体

```
ホーム（S-10）
├─ 今日のやること（S-20〜S-27）… 服薬、歩数、記録、薬の管理
├─ ゲームをはじめる（S-30〜S-36）… すごろく、クイズ、スタンプ帳、引き換え所
├─ 家族（S-40〜S-45）… 小さめのボタン
└─ 設定（S-50〜S-57）… 小さめのボタン
```

| 番号 | 要件 |
|---|---|
| R-05-01 | ホームに「今日のやること」と「ゲームをはじめる」の2つの入り口を大きく置く。どちらも文字と絵の両方を付ける（絵だけにしない） |
| R-05-02 | 家族と設定は、2つの入り口の下に小さめのボタンで置く |
| R-05-03 | 画面の下にタブを並べない。今日のやること、ゲームモード、家族、設定の各画面の上に、文字付きの「ホームへ」ボタンを置く |
| R-05-04 | アプリを開いたときは、いつもホームを表示する。前回最後に見ていた画面には戻さない（迷わないため） |
| R-05-05 | 画面の階層は、ホームから3段（仮）までにする。どの画面にも「戻る」を文字付きで置く |
| R-05-06 | 今日のやることとゲームモードの間は、ホームを通って行き来する。ただし、今日のやることで記録を終えたときだけ「ゲームをはじめる」ボタンを出し、そのまま遊びに行けるようにする |

## 初回の流れ（案内）

アカウントは裏で自動的に作る（R-08-01）。案内では入力をできるだけ求めず、どの画面も「あとで」で飛ばせる。

服薬する人の流れ：

1. S-01 はじめに（1〜3枚、何ができるアプリかを短く）
2. S-02 呼び名の入力
3. 「招待を受けましたか？」 → はい：S-03 招待コードの入力 ／ いいえ：次へ
4. S-04 最初の薬の登録（「薬を飲んでいない」「あとで」も選べる）
5. S-05 通知の許可の説明 → iOSの許可の画面（薬を登録した人だけ）
6. S-07 健康の記録を保存することへの同意
7. S-06 歩数の許可の説明 → iOSの許可の画面
8. ホームへ。ゲームの遊び方は、初めて「ゲームをはじめる」を押したときに案内する

招待リンクから入った家族の流れ：3 の招待コードを最初から入れた状態にし、4 と 5 は「薬を飲んでいる方はこちら」として飛ばせるようにする。

|---|---|
| R-05-10 | 案内は最大7画面（仮）。どの画面にも「あとで」を置き、飛ばした項目は今日のやることの「はじめの準備」に残す |
| R-05-11 | 呼び名のほかに、案内で文字を入力させない（薬の名前を除く） |

## ホーム（S-10）

上から順に、次のものを置く。

| 順 | 内容 | 関係する要件 |
|---|---|---|
| 1 | 知らせ（通知がオフ、歩数が届いていない、など。あるときだけ） | R-03-28、R-04-42 |
| 2 | 入り口「今日のやること」：今日の服薬と歩数のひとこと | R-05-20 |
| 3 | 入り口「ゲームをはじめる」：今の旅の場所と旅ポイント | R-05-21 |
| 4 | 家族から届いた応援（届いたときだけ） | R-10-30 |
| 5 | 小さめのボタン：家族、設定 | R-05-02 |

| 番号 | 要件 |
|---|---|
| R-05-20 | 「今日のやること」の入り口には、今日の様子をひとことで添える（例：「お薬 あと1回　歩数 3,200歩」）。全部記録できた日は「今日のお薬はすべて記録できました」とする |
| R-05-21 | 「ゲームをはじめる」の入り口には、今いる場所と今の旅ポイントを添える（例：「鎌倉の手前　旅ポイント 120」） |
| R-05-22 | 2つの入り口は、同じ大きさで縦に並べる。どちらかを押すのを強いる印（赤い点の数字など）は付けない（P-02-02） |
| R-05-23 | ホームでは、達成率を％や点数で表示しない。できていない日を責めない（P-02-02） |
| R-05-24 | 連続記録の日数や、ログインのボーナスは表示しない（P-02-02） |
| R-05-25 | 1の知らせは、いちばん大事なもの1つだけを出す。閉じられるものは閉じた後しばらく出さない（R-04-43） |

| 3 | 今日の旅ポイント：届いた分と届く見込み | R-04-11 |

## ゲームモード（S-30〜S-36）

「ゲームをはじめる」を押すと、すごろくの盤面（S-30）が開く。

| 番号 | 要件 |
|---|---|
| R-05-40 | 盤面（S-30）は自分の駒を中心に表示する。指で動かして盤面全体を見られる。家族の駒は呼び名の頭文字かアバターで区別する（R-02-24） |
| R-05-41 | 盤面の下に「サイコロを振る」ボタンを大きく置く。サイコロはいつでも何度でも振れる（R-02-05） |
| R-05-42 | 「まとめて振る」ボタンを置く（R-02-16）。押すと結果だけを順に表示し、止まったマスの出来事はまとめて後から見られる |
| R-05-43 | サイコロの動きと駒の移動の演出は、押すと飛ばせる。端末の「視差効果を減らす」設定がオンのときは、動きを少なくする |
| R-05-44 | マスに止まったときの出来事（S-32、S-33）は、閉じるまで待つ。時間で消えたり、時間内に答えを求めたりしない（R-02-30、P-02-07） |
| R-05-45 | 盤面の上に、今の旅ポイントと、引き換え所（S-35）、スタンプ帳（S-34）、クイズの一覧（S-36）へのボタンを置く |
| R-05-46 | 引き換え所では、引き換えの前に確認を出す。旅ポイントが足りないものも並べてよいが、「足りない」と責める言葉は使わない |
| R-05-47 | 家族の順位、他の人との比較は表示しない（R-10-22） |
| R-05-48 | 家族の駒を押すと、その人の呼び名と集めたスタンプの数を見られる。健康の記録の中身は出さない（R-10-21） |
| R-05-49 | ゲームモードでは、服薬の記録や「やっていないこと」を表示しない。旅ポイントは記録で届くことだけを、引き換え所に一言添える |

## 見やすさと操作のしやすさ

画面に関わることだけをここで決める。アクセシビリティの全体の方針は 08 で扱う。

| 番号 | 要件 |
|---|---|
| R-05-80 | 文字の大きさは iPhone の設定（Dynamic Type）に合わせる。最大の大きさでも、文字が切れたり重なったりしない |
| R-05-81 | アプリの中でも文字の大きさを「ふつう・大きい・とても大きい」（仮）から選べる。初期値は「大きい」（仮） |
| R-05-82 | 押せる部分は 44×44pt 以上にする。主なボタン（2つの入り口、「飲んだ」「サイコロを振る」）はそれより大きくする |
| R-05-83 | 長押し、スワイプ、2本指の操作だけでできる機能を作らない。必ずボタンでもできるようにする |
| R-05-84 | 色だけで意味を伝えない。記録の状態は文字か印でも表す |
| R-05-85 | VoiceOver で、すべてのボタンと記録の状態が読み上げられる |
| R-05-86 | 画面が明るさの設定（ダークモード）に合わせて切り替わる |
| R-05-87 | 時間で消える表示や、時間内の操作を求める画面を作らない（P-02-07） |
