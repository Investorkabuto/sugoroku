# 01 全体方針

状態：仮確定（2026-10-16 更新：MVPに見守り・家族の旅・サーバーを含める）

## 目的

毎日の健康タスク（服薬、歩数など）を記録するとサイコロが振れ、家族と同じ盤面で日本を旅する。
服薬と運動を続けられる習慣にし、離れて暮らす家族の見守りにもつなげる。

## 開発方針

| 項目 | 方針 |
|---|---|
| フレームワーク | Flutter（1つのコードで iOS・Android・Web） |
| 最初に出すOS | iOS |
| 後から出すもの | 家族向けWeb見守り画面 → Android |
| 開発環境 | Mac + Xcode + Flutter SDK |
| 配布（テスト） | TestFlight で家族に配る |
| 配布（公開） | App Store |

## 要件

| 番号 | 要件 |
|---|---|
| R-01-01 | 最初の版（MVP）は iPhone で動作する |
| R-01-02 | 対応するiOSは iOS 16 以上（仮）。高齢の方の古いiPhoneを考え、試作時に見直す |
| R-01-03 | iPad は対象外（iPhone用画面のまま表示されればよい） |
| R-01-04 | 画面の言語は日本語のみ |
| R-01-05 | コードは Android・Web でも動かせる構成にし、iOSだけの処理（HealthKit、通知）は services 層に閉じ込める |
| R-01-06 | MVPから見守りと家族の旅を入れ、サーバー（Firebase）を用意する |

最初の到達点：**iPhone実機で服薬通知が鳴り、通知から記録するとサイコロが振れる。**
公開時の到達点：**家族を招待し、同じ地図で旅をしながら、記録の様子を見守れる。**

| 達成率の計算とサイコロ | ○ | |

## 前提と制約

- iOSで予約できる通知は64件まで。薬の数×時刻が多い場合は、近い日の分から予約して毎日補充する（詳細は 03）
- 消音モードでも鳴る「重要な通知」は Apple の特別な許可が必要なため、MVPでは使わない
- サーバーはFirebase（Auth、Firestore、Cloud Functions、Cloud Messaging）。Cloud Functionsを使うため有料のBlazeプランになる（利用量に応じた課金）
- App Storeの審査では、アカウントを作れるアプリにアプリ内でのアカウント削除が求められる
- 実機テストとストア公開には Apple Developer Program（年会費）の登録が必要
- アプリは薬局・医師の指示どおりに知らせるだけで、飲み方を判断しない（詳細は 08）
